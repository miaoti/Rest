🔍 ROOT CAUSE ANALYSIS
─────────────────────
**ROOT CAUSE:**
The failure occurs in `ts-price-service` during `UPDATE ts.price_config` operation where MySQL throws `Data truncation: Data too long for column 'route_id' at row 1`. The exception originates from `SQLExceptionsMapping.translateException()` in MySQL JDBC driver.

**FIX:**
Increase the `route_id` column size in the `ts.price_config` table to accommodate the incoming data length, or validate and truncate the `route_id` data in `ts-price-service` before database insertion to match the column's maximum allowed length.
