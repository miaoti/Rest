🔍 ROOT CAUSE ANALYSIS
─────────────────────
**ROOT CAUSE:**
The failure occurred in `ts-route-service` at operation `GET /api/v1/routeservice/routes/{routeId}` with HTTP 403 status. The exact error is `RequestRejectedException` thrown by Spring Security firewall due to URL containing malicious string ";". The failure point is in `ThreadPoolExecutor.runWorker()` where the request was rejected during security validation.

**FIX:**
Add URL validation and sanitization in `ts-route-service` to properly handle semicolon characters in routeId parameters, or configure Spring Security's `HttpFirewall` to allow such URLs by implementing a custom `StrictHttpFirewall` with `setAllowSemicolon(true)`.
