🔍 ROOT CAUSE ANALYSIS
─────────────────────
**ROOT CAUSE:**
The failure occurs in `ts-route-service` at operation `GET /*` with HTTP 403 status. The exact cause is `RequestRejectedException` thrown by Spring Security firewall due to non-normalized URL. The exception originates from `ThreadPoolExecutor.runWorker()` indicating the request was rejected during security validation before reaching application logic.

**FIX:**
Configure Spring Security's `HttpFirewall` to allow non-normalized URLs by implementing `StrictHttpFirewall` with `setAllowUrlEncodedSlash(true)` and `setAllowUrlEncodedPercent(true)` in the security configuration to permit the malformed URL pattern being rejected.
