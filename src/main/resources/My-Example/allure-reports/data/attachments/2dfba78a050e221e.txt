🔍 ROOT CAUSE ANALYSIS

FIX: Correct client request to send integer value for `state` field (e.g., `1` or `0`) instead of boolean `true`. Alternatively, update `QueryInfo.state` type in `ts-order-other-service` to `Boolean` if boolean representation is intended.
