🔍 ROOT CAUSE ANALYSIS
─────────────────────
**ROOT CAUSE:**
The failure occurs in `ts-route-service` at operation `GET /*` with HTTP 403 status due to `RequestRejectedException` caused by non-normalized URL. The exception is thrown during thread pool execution in `ThreadPoolExecutor.runWorker()`.

**FIX:**
Configure Spring Security's `HttpFirewall` to allow non-normalized URLs by implementing `StrictHttpFirewall` with `setAllowUrlEncodedPercent(true)` and `setAllowUrlEncodedSlash(true)` in the security configuration to permit the malformed URL pattern being rejected.
