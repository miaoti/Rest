🔍 ROOT CAUSE ANALYSIS
─────────────────────
**ROOT CAUSE:**
The failure occurred in `ts-admin-travel-service` during DELETE request to `/api/v1/admintravelservice/admintravel/{tripId}` with HTTP 403 status. The exact cause is `RequestRejectedException` thrown by Spring Security firewall due to URL containing malicious string "%25" (URL-encoded percent sign). The exception originated from `ThreadPoolExecutor.runWorker` indicating the request was rejected before reaching application logic.

**FIX:**
Configure Spring Security's `HttpFirewall` to permit requests containing URL-encoded percent signs by implementing custom `StrictHttpFirewall` with `setAllowUrlEncodedPercent(true)` or add exception path configuration to bypass security firewall for specific admin endpoints that legitimately require such URL encoding.
