🔍 ROOT CAUSE ANALYSIS
─────────────────────
**ROOT CAUSE:**
The failure occurs in `ts-price-service` during `UPDATE ts.price_config` operation where MySQL throws `Data truncation: Data too long for column 'route_id' at row 1` due to `com.mysql.cj.jdbc.exceptions.MysqlDataTruncation` exception.

**FIX:**
Increase the `route_id` column size in the `ts.price_config` table to accommodate the incoming data length, or validate and truncate the `route_id` data to fit the existing column constraints before database insertion.
