🔍 ROOT CAUSE ANALYSIS
─────────────────────
**ROOT CAUSE:**
The failure occurs in `ts-price-service` during `INSERT ts.price_config` operation where MySQL throws `Data truncation: Data too long for column 'route_id' at row 1`. The `route_id` column cannot accommodate the incoming data length.

**FIX:**
Increase the `route_id` column size in the `ts.price_config` table to accommodate the maximum expected data length, or validate and truncate the input data in `ts-price-service` before the database insert operation.
