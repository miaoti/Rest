🔍 ROOT CAUSE ANALYSIS
─────────────────────
**ROOT CAUSE:**
The failure occurs in `ts-admin-travel-service` during DELETE operation `/api/v1/admintravelservice/admintravel/{tripId}` with HTTP 403 status. The exact error is `RequestRejectedException` thrown by Spring Security firewall due to URL containing malicious string "%25" (URL-encoded % character). The exception originates from `ThreadPoolExecutor.runWorker` indicating the security filter rejected the request before processing.

**FIX:**
Configure Spring Security's `HttpFirewall` to permit the URL pattern containing encoded characters by implementing custom `StrictHttpFirewall` with `setAllowUrlEncodedPercent(true)` or add exception path to `antMatchers()` in security configuration to allow the specific endpoint.
