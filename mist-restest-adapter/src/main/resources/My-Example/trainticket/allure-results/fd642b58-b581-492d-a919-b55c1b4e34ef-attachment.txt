🔍 ROOT CAUSE ANALYSIS
─────────────────────
**ROOT CAUSE:**
The failure occurs in `ts-price-service` during `UPDATE ts.price_config` operation with SQLIntegrityConstraintViolationException due to duplicate entry 'Express-RT-12345' for key 'route_type_idx' in MySQL database.

**FIX:**
Implement duplicate detection and handling in the `ts-price-service` before executing the UPDATE operation. Add pre-check logic to verify if the route_type 'Express-RT-12345' already exists, or modify the database constraint to allow updates instead of strict uniqueness enforcement.
